# Premium Todo App (MERN Stack)

A full-stack, feature-rich To-Do application with a premium glassmorphism UI, dark mode, and smart features.

## 🔴 Live Demo
- **Frontend:** [https://premium-todo-red.vercel.app](https://premium-todo-red.vercel.app)
- **Backend API:** [https://premium-todo.onrender.com](https://premium-todo.onrender.com)

## ✨ Features
- **Authentication:** Secure Login/Register using JWT.
- **Task Management:** Create, Read, Update, Delete (CRUD) tasks.
- **Smart Features:** Search, Filter (by priority/status), and Sort tasks.
- **Premium UI:** Custom Glassmorphism design, Notebook style background.
- **Dark Mode:** Toggle between light and dark themes.
- **Custom Datepicker:** Set due dates with a premium UI.
- **Animations:** Smooth transitions using Framer Motion.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Redux Toolkit, Framer Motion, Headless UI.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB Atlas, Mongoose.
- **Deployment:** Vercel (Frontend), Render (Backend).

## 🚀 Run Locally
1. Clone the repository: `git clone https://github.com/mohd-arzaan/premium-todo.git`
2. Go to server folder: `cd server` -> `npm install` -> add `.env` file.
3. Run backend: `npm run dev`
4. Go to client folder: `cd client` -> `npm install`.
5. Run frontend: `npm run dev`
